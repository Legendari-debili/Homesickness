# A bad game made by smelly teenagers from Latvia​

A green ball called Debils wants to travel to the end wall, but, unfortunately, he's homesick,
so he wants to return back home from his journey. Help him reach the end wall and return back home safely!
The journey gets lengthier and lengthier, so it will be more difficult, but more rewarding to reach the end and return.

Controls:
- A & D - move left and right, respectively;
- W or Space - launch;
- Escape - quit
